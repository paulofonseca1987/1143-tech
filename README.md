# 1143.tech

*Brave & Bellicose.* A showcase of modern Portuguese military technology.

One static page (`index.html`), no build step. Fonts come from Google Fonts.

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Hosted on Vercel, deployed from `main`. Framework preset: **Other**, no build command, output directory: the repo root.
